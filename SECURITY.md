# Security policy

This is an educational project and has not been independently audited.

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/ericliswan/keyward/security/advisories/new). Do not open a public issue, and never include real passwords or vaults in a report.

You can expect an acknowledgement within 7 days and an assessment within 30 days.
